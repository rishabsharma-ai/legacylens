# Mainframe Glossary

- **CICS**: the transaction server that runs our online screens.
- **COMMAREA**: a block of memory passed from one CICS program to the next.
- **BMS map**: the definition of a 3270 screen layout.
- **VSAM KSDS**: a keyed file, similar to a table with a primary key.
- **AIX**: an alternate index on a VSAM file, like a secondary index.
- **GDG**: a generation data group, a numbered series of versions of one file.
- **JCL**: job control language, the scripts that run batch programs.
- **Copybook**: a shared piece of COBOL source, usually a record layout, pulled in
  with COPY.
- **Abend**: an abnormal end, a crash. S0C7 means bad numeric data.
