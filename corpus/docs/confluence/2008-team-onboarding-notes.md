# Team Onboarding Notes

Welcome to the cards team. In your first week:

1. Request access to the development region and the source library.
2. Read the System Overview and the Nightly Batch Runbook.
3. Shadow the on-call engineer for one nightly batch.

Our stand-up is at 9:30 every weekday. Code reviews need one approval from a senior
engineer. Production changes go through the weekly change board on Thursdays.
