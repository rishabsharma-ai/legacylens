# CardDemo knowledge bundle

Start with a folder, then follow the links between pages.

- [Programs](programs/index.md) (44): COBOL programs. Online ones run under CICS; batch ones run from JCL jobs.
- [Jobs](jobs/index.md) (46): JCL jobs: the batch schedule's units of work, each a list of steps.
- [Transactions](transactions/index.md) (20): CICS transaction IDs: the four-letter codes a user types to start a program.
- [Screens](screens/index.md) (21): BMS mapsets: the 3270 screens online programs send and receive.
- [Copybooks](copybooks/index.md) (65): Copybooks: shared record layouts and constants that programs COPY in.
- [Datasets](datasets/index.md) (73): Data stores: VSAM files, sequential files and GDGs, Db2 tables, IMS segments and MQ queues.
